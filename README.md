# CADverse

### **CAD + Universe** — 기구학 교육을 위한 AR 기반 실시간 상호작용 다중 사용자 시뮬레이션 플랫폼

설계한 CAD 모델을 실시간 물리 시뮬레이션과 연동하여 모바일 기기로 AR상에서 인터랙션할 수 있는 시스템입니다.

```
[Fusion 360]
     │ 플러그인으로 익스포트
     ▼
[시뮬레이션 서버]  ◄── QUIC P2P ──►  [AR 클라이언트]
  Rust + PyChrono                     Unity XR (Android)
```

## 요구사항

### 시뮬레이션 서버

- Windows 10 이상
- Python 환경 내장 — 별도 설치 불필요

### CAD 플러그인

- Autodesk Fusion 360
- **부품 이름은 반드시 영문/숫자만 사용** (한글 불가)

### AR 클라이언트

- ARCore를 지원하는 Android 기기
- Android 9.0 이상

## 설치

### 시뮬레이션 서버

1. `cadverse-0.1.0-server.zip` 압축 해제
2. 폴더 내 `server.exe` 실행

### CAD 플러그인

1. `cadverse-0.1.0-cad-plugin.zip` 압축 해제
2. Fusion 360 실행 → 상단 메뉴 `유틸리티` > `애드인` > `스크립트 및 애드인`
3. `애드인` 탭에서 `+` 버튼 클릭 → 압축 해제한 `CADverse` 폴더 선택
4. 목록에서 `CADverse` 선택 후 `실행` 클릭 (매 실행 시) 또는 `시작 시 실행` 체크 (자동 실행)

### AR 클라이언트

1. Android 기기에서 `설정` > `보안` > `알 수 없는 앱 설치` 허용
2. `cadverse-0.1.0-client.apk`를 기기로 옮겨 설치

## 사용 방법

### 전체 흐름

```
1. 플러그인으로 지정 폴더에 모델 추출
2. 서버 실행 → 추출한 폴더 선택 → 시뮬레이션 시작(QR 나타남)
3. 클라이언트로 QR 스캔 → AR 인터랙션
```

---

### 1단계 — 모델 익스포트 (플러그인)

> 부품 이름에 한글이 포함되어 있으면 익스포트가 차단됩니다. 영문으로 변경 후 시도하세요.

1. 익스포트할 디자인을 Fusion 360에서 열기
2. `유틸리티` > `애드인` > `CADverse` 실행
3. 저장 폴더 선택
4. 완료 후 선택한 폴더에 `metadata.json`과 `meshes/` 폴더가 생성됨

---

### 2단계 — 서버 실행

1. `server.exe` 실행 후 사용자 이름과 그룹 이름 입력
2. 화면에 표시된 **그룹 비밀번호** 기록 (그룹 접속에 필요)
3. 메뉴에서 `1. 시뮬레이션 시작` 선택
4. 1단계에서 익스포트한 폴더 경로 입력
5. QR 코드 창이 표시되면 클라이언트로 스캔할 준비 완료

**서버 메뉴**

| 번호 | 기능                                        |
| ---- | ------------------------------------------- |
| 1    | 시뮬레이션 시작                             |
| 2    | 시뮬레이션 종료                             |
| 3    | 다른 그룹원의 시뮬레이션 QR 표시            |
| 4    | 그룹 정보 보기(그룹명, 비밀번호, 그룹원 등) |
| 5    | 그룹원의 모델을 받아 내 서버에서 실행       |
| 0    | 종료                                        |

> **교사-학생 예시** — 교사가 서버를 실행하고 QR을 공유하면 학생이 스캔해 AR로 시뮬레이션을 관람합니다.  
> 학생이 직접 모델을 조작하려면: 교사 서버 메뉴 **5번**으로 학생에게 모델 전송 → 학생 서버에서 시뮬레이션 시작.

---

### 3단계 — AR 클라이언트

1. 앱 실행 후 서버와 **동일한 그룹 이름과 비밀번호** 입력
2. 카메라로 서버의 QR 코드 스캔
3. 모델이 마커 위에 배치되면 AR 씬 시작
4. 화면을 터치하여 모델과 인터랙션

> 클라이언트의 그룹원 이름과 QR로 접속한 서버의 그룹원 이름이 동일해야 인터랙션이 가능합니다.

> 마커(QR)가 화면에서 사라지더라도 모델은 마지막 위치에 고정됩니다. 다시 마커를 비추면 모델이 마커 위치로 재부착됩니다.

## 기술 세부사항

### 메타데이터 스키마

플러그인이 생성하는 `metadata.json` 구조입니다.

```json
{
  "info": {
    "version": "2.0",
    "coordinate_system": "Right-Handed (Z-up)",
    "units": "Translation: cm, Rotation: Degree"
  },
  "transforms": {
    "part_name": [ /* Row-major 4×4 변환행렬, 16개 float */ ]
  },
  "joints": [
    {
      "name": "joint_name",
      "type": "Revolute | Slider | Rigid",
      "connected_parts": { "parent": "...", "child": "..." },
      "axis": [x, y, z],
      "origin": [x, y, z],
      "limits": { "min": 0.0, "max": 90.0 }
    }
  ]
}
```

### 좌표계 변환

Fusion 360은 오른손 Z-up 좌표계를 사용하며, Unity는 왼손 Y-up 좌표계를 사용합니다.

| Fusion 360  | Unity           |
| ----------- | --------------- |
| X (우)      | X (우)          |
| Y (화면 안) | Z (전방)        |
| Z (상)      | Y (상)          |
| 단위: cm    | 단위: m (×0.01) |

### P2P 네트워킹

iroh(QUIC) 기반 P2P를 사용합니다. 릴레이를 통해 방화벽·NAT를 넘어 연결되므로 **대면 수업**과 **원격 수업**에서 동일한 사용 경험을 제공합니다.

- **Coordinator**: 그룹의 첫 참가자가 자동으로 담당. 피어 등록 및 브로드캐스트 관리
- **시뮬레이션 서버**: MidServer 역할. 시뮬레이션 상태를 클라이언트에 브로드캐스트
- **AR 클라이언트**: QUIC 스트림으로 메타데이터·메시 파일 수신, 터치 입력 전송

### AR 마커 추적

AR Foundation의 이미지 트래킹을 사용합니다.

- 서버가 자신의 노드 ID(32바이트)를 QR 코드로 인코딩해 화면에 표시
- 클라이언트가 QR을 스캔해 서버에 연결한 뒤 QR 이미지를 AR 마커로 등록
- 마커 추적 소실 시 `ARAnchor`로 전환해 마지막 위치 유지

### 서버 빌드 구조

```
Shell (build-server.ps1)
  └── Cargo (build.rs)
        └── conda-pack
```

- **Shell**: Conda 경로 설정 및 환경 활성화
- **Cargo (build.rs)**: `environment.yml` 변경 감지 시 `conda env update` 자동 실행. 릴리즈 빌드 시 `conda-pack`으로 Python 환경을 `python_env.tar.gz`에 번들링
- **배포**: `server.exe` 첫 실행 시 `python_env.tar.gz`를 자동 해제
