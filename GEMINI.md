# CADverse Project Overview

This project is a multi-component system for visualizing CAD data in an augmented reality environment. It consists of a CAD plugin, a simulation server, and an AR client.

## Components

### 1. CAD Plugin (`cad_plugin`)

*   **Technology:** Python, Autodesk Fusion 360 API
*   **Purpose:** This plugin extracts 3D model data from a Fusion 360 design. It saves the models as `.obj` files and their transformation matrices into a `transforms.json` file.
*   **Usage:** To use the plugin, run the `extract_mesh/extract_mesh.py` script from within the Fusion 360 script environment.

### 2. Simulation Server (`sim_server`)

*   **Technology:** Rust, Axum, Tokio, PyO3, PyChrono
*   **Purpose:** This server loads the CAD data generated by the plugin, runs a physics simulation using PyChrono (via PyO3), and serves the simulation data to the AR client via WebSockets.
*   **Setup and Building:**
    ```powershell
    # Navigate to the sim_server directory
    cd sim_server

    # Setup Python environment
    .\setup_pychrono_env.ps1

    # Set environment variables for PyO3
    .\set_pyo3_env.ps1

    # Build the server (for development)
    cargo build
    
    # Run the server
    cargo run
    ```
*   **Release Build:**
    For a release build that bundles the Python environment, use `cargo build --release`. See `sim_server/README_BUILD.md` for more details.
*   **Development Conventions:**
    *   **Logging:** The project uses the `tracing` crate for logging.
    *   **Error Handling:** `anyhow` is used for error handling.

### 3. AR Client (`ar_client_retry`)

*   **Technology:** Unity, ARFoundation (ARCore/ARKit), XR Interaction Toolkit
*   **Purpose:** This is an augmented reality application for Android and iOS that connects to the simulation server. It receives the simulation data and visualizes the 3D models in the real world.
*   **Building and Running:**
    *   Open the `ar_client_retry` directory as a Unity project.
    *   Build the project for your target platform (Android or iOS).

### 4. Interface (`interface`)

*   **Purpose:** This directory contains the data structure definitions and code generation for the communication protocol between the `sim_server` and the `ar_client_retry`. The `codegen` directory suggests that code is automatically generated for both the client and server to ensure they stay in sync.

## Overall Workflow

1.  A CAD designer uses the `cad_plugin` in Autodesk Fusion 360 to export a 3D model.
2.  The `sim_server` loads the exported `.obj` and `transforms.json` files.
3.  The `sim_server` starts a simulation and opens a WebSocket server.
4.  The `ar_client_retry` application, running on a mobile device, connects to the `sim_server`.
5.  The client receives simulation data and renders the 3D model in the user's environment using AR.
